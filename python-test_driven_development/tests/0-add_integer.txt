==============================
How to Use 0-add_integer
==============================

This module defines an integer addition function ``add_integer(a, b=98)``.

Usage
=====

Importing the function:
    >>> add_integer = __import__('0-add_integer').add_integer

Regular addition:
    >>> add_integer(1, 2)
    3

    >>> add_integer(100, -2)
    98

Default argument b=98:
    >>> add_integer(2)
    100

Float casting to integer:
    >>> add_integer(2.3, 4.2)
    6

    >>> add_integer(2.9, 0.2)
    2

    >>> add_integer(-2.9, -0.2)
    -2
