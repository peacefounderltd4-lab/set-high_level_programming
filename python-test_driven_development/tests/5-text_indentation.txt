==============================
How to Use 5-text_indentation
==============================

This module defines a text indentation function ``text_indentation(text)``.

Usage
=====

Importing the function:
    >>> text_indentation = __import__('5-text_indentation').text_indentation

Normal string test:
    >>> text_indentation("Holberton. School? How: are you")
    Holberton.
    <BLANKLINE>
    School?
    <BLANKLINE>
    How:
    <BLANKLINE>
    are you

String with trailing/leading spaces:
    >>> text_indentation("   Hello.   How are you?   Fine:   thanks   ")
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    Fine:
    <BLANKLINE>
    thanks

String with blank line:
    >>> text_indentation("Hello.\n\nWorld?")
    Hello.
    <BLANKLINE>
    <BLANKLINE>
    World?
    <BLANKLINE>

Non-string test:
    >>> text_indentation(12)
